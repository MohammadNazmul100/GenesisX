🚀 GENESIS-X: The Self-Learning AI Model
A simple guide to get started with GenesisX:
Clone and install:
git clone https://github.com/MohammadNazmul100/GenesisX.git
cd GenesisX
pip install -r requirements.txt
Run the application:
cd src
streamlit run main.py
Once the app opens in your browser, click the "📚 Documentation" button at the top to see full details about model architecture, training, and visualizations.
Requirements: Python 3.8+, PyTorch, Streamlit (all included in requirements.txt)
