# 🚀 GENESIS-X: The Self-Learning AI Model

Welcome to GenesisX, a streamlined AI experience! Getting started is simple.

## ⚡ Quick Start

1. Clone and install:
   - git clone https://github.com/MohammadNazmul100/GenesisX.git
   - cd GenesisX
   - pip install -r requirements.txt

2. Launch the app:
   - cd src
   - streamlit run main.py
